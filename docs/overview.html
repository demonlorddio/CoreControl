AI Desktop Assistant

CoreControl

A secure, locally-hosted AI daemon that connects Telegram and voice input to your machine via a custom MCP server, OS automation hooks, and an online/offline reasoning engine.

v1.0.0 Python 3.11+ MCP 2.0 Claude API Ollama offline PyQt6 overlay Windows · macOS · Linux
System Architecture

How it fits together

All modules are connected through the orchestrator. The MCP server runs as a subprocess over stdio JSON-RPC. HITL gating intercepts risky tool calls before they reach the OS.

Security · HITL Middleware

Human-in-the-Loop approval flow

High-risk tool calls are intercepted before execution. The orchestrator pauses and waits up to 300 s for a decision over Telegram.

1
Orchestrator flags tool call

execute_terminal_command, click_coordinate, or type_text triggers the HITL filter.

2
Confirmation card sent

Tool name, JSON arguments preview, and a live screenshot are dispatched to all whitelisted Telegram user IDs.

3
User decides
✅ Approve ✏️ Edit args ❌ Deny
4
Orchestrator resumes or aborts

Approved → MCP tool executes. Edited → user's modified JSON used. Denied → error injected into LLM context window.

Quick Start

Get running in five steps

01
Create a virtual environment and install dependencies python -m venv .venv .venv\Scripts\activate # Windows pip install -r requirements.txt
02
Set your Telegram bot token and user ID in config/settings.json

Get a token from @BotFather. Get your numeric ID from @userinfobot.

03
Export your Anthropic API key (online mode) set ANTHROPIC_API_KEY=sk-ant-...
04
Pull a model and start Ollama (offline mode) ollama pull qwen2.5-coder:7b ollama serve
05
Launch CoreControl python main.py # full daemon (Telegram + overlay) python -m src.orchestrator # interactive REPL only
Security Model

Defence in depth

Telegram auth

All messages from non-whitelisted user IDs are silently dropped before reaching the orchestrator.

Command whitelist

execute_terminal_command validates against a prefix whitelist and an explicit blacklist before any subprocess call.

HITL gating

click_coordinate, type_text, and terminal commands require human approval. Auto-deny on timeout.

PyAutoGUI failsafe

Moving the mouse to the top-left corner of the screen aborts all active automation immediately.

Stderr-only logging

The MCP server writes all diagnostics to stderr. stdout is reserved for JSON-RPC transport — mixing them corrupts the protocol.

Subprocess sandbox

A configurable timeout (default 30 s) limits how long any shell command can run. Output is capped at 10 000 characters.
