## What Was Done

### 1. Fixed `NameError: st is not defined` in `overlay.py`

**File:** `src/gui/overlay.py` — `GreatSageAvatar.paintEvent()` method (lines 211–225)

**Symptom:** Application crashed on every frame render with:
```
NameError: name 'st' is not defined
```

**Root cause:** A variable named `st` (likely from a shorter variable name) was referenced in 4 comparison expressions inside `paintEvent`, but only `self._state` exists on the class.

**Fix:** Changed all 4 occurrences:
```python
# Before (broken)
if st == NPCState.LISTENING:
    dot_color = QColor(80, 180, 255)
elif st == NPCState.PROCESSING:
    ...
elif st == NPCState.SPEAKING:
    ...
else:
    ...
if st == NPCState.IDLE and self._is_blinking:
    ...

# After (fixed)
if self._state == NPCState.LISTENING:
    dot_color = QColor(80, 180, 255)
elif self._state == NPCState.PROCESSING:
    ...
elif self._state == NPCState.SPEAKING:
    ...
else:
    ...
if self._state == NPCState.IDLE and self._is_blinking:
    ...
```

### 2. Fixed Missing System Tray Icon Warning

**File:** `src/gui/overlay.py` — `OverlayWidget.__init__()` method (system tray section)

**Symptom:** Console spam on every tray redraw:
```
QSystemTrayIcon::setVisible: No Icon set
```

**Root cause:** `QSystemTrayIcon` requires an icon to be set via `setIcon()` before it can display. The tray was created but never given a pixmap.

**Fix:** Added `QIcon` import and set a minimal 16×16 blue-filled pixmap:
```python
# Added to PyQt6.QtGui imports
from PyQt6.QtGui import QIcon,  # <-- added

# In __init__, after creating self._tray
_icon_pix = QPixmap(16, 16)
_icon_pix.fill(QColor(30, 60, 120))
self._tray.setIcon(QIcon(_icon_pix))
```

### 3. Fixed Bounce Timer Running Unconditionally

**File:** `src/gui/overlay.py` — `GreatSageAvatar.__init__()` method

**Symptom:** Avatar was bouncing (vertical oscillation) even in IDLE state where it shouldn't be, creating an unintended animation.

**Root cause:** `self._bounce_timer.start(50)` was called unconditionally in `__init__`, starting the bounce loop immediately on creation.

**Fix:** Commented out the auto-start line; bounce is now opt-in via `set_bounce(True)`:
```python
# Before
self._bounce_timer = QTimer(self)
self._bounce_timer.timeout.connect(self._tick_bounce)
self._bounce_timer.start(50)  # ← always started

# After
self._bounce_timer = QTimer(self)
self._bounce_timer.timeout.connect(self._tick_bounce)
# Start disabled — enable only when needed
# self._bounce_timer.start(50)
```

## How Everything Works Now

### Architecture (current state)

```
┌─────────────────────────────────────────────────────────┐
│                    main.py (entry point)                 │
│  ┌─────────────────┐      ┌─────────────────────────┐   │
│  │ Async Orchestrator│      │  PyQt6 Overlay Thread   │   │
│  │  (main thread)   │◄────►│  (daemon thread)        │   │
│  └────────┬────────┘      └───────────┬─────────────┘   │
│           │                           │                 │
│    ┌──────┴──────┐            ┌───────┴────────┐       │
│    │ Network     │            │  GreatSageAvatar │       │
│    │ Monitor     │            │  (GIF + state dot)│       │
│    └──────┬──────┘            └───────┬────────┘       │
│    ┌──────┴──────┐            ┌───────┴────────┐       │
│    │ MCP Client  │            │  SpeechBubble    │       │
│    │ (stdio)     │            │  (text display)  │       │
│    └──────┬──────┘            └───────┬────────┘       │
│    ┌──────┴──────┐            ┌───────┴────────┐       │
│    │ HITL Filter │            │  HITLModal       │       │
│    │ (approvals) │            │  (approve/edit/  │       │
│    └──────┬──────┘            │   deny buttons)  │       │
│    ┌──────┴──────┐            └───────┬────────┘       │
│    │Online/       │                    │                │
│    │Offline LLM   │            ┌───────┴────────┐       │
│    └─────────────┘            │  System Tray     │       │
│                                │  (Show/Hide/     │       │
│  ┌─────────────────┐          │   Top/Quit)      │       │
│  │ AudioRecorder   │          └──────────────────┘       │
│  │ (mic + Whisper) │                                   │
│  └─────────────────┘                                   │
│  ┌─────────────────┐                                   │
│  │ HotkeyTrigger   │  (Ctrl+Space globally)             │
│  └─────────────────┘                                   │
└─────────────────────────────────────────────────────────┘
```

### Signal Flow

1. **Voice trigger** → HotkeyTrigger/Ctrl+Space → `overlay.set_state(LISTENING)`
2. **Audio capture** → `AudioRecorder` records mic → VAD detects speech end → Whisper transcribes
3. **Transcription callback** → `main.py` → `orch.process_prompt(text)` → returns `ProcessResult`
4. **Result delivery** → `overlay.response_received.emit(result.text)` → `overlay.speak(text)`
5. **Speech display** → `SpeechBubble.speak(text)` shows text for `duration_ms`
6. **State return** → `overlay.set_state(IDLE)` when speech ends

### Tool Execution Flow

1. LLM receives prompt + screenshot → decides to call tool(s)
2. For each tool call:
   - If in `AUTO_APPROVE_TOOLS` → execute immediately
   - If in `HIGH_RISK_TOOLS` → show HITL modal → await user decision
   - Execute via MCP stdio → collect result → post-action screenshot
3. Loop up to 10 iterations with tool results fed back to LLM
4. Final response delivered to overlay speech bubble

### State Machine (Avatar)

```
IDLE ──Ctrl+Space──► LISTENING ──transcription──► PROCESSING
  ▲                                              │
  └───────────speak() ends───────────────────────┘
                         │
                    ┌────▼────┐
                    │SPEAKING │
                    └────┬────┘
                         │
                    (8s timer → IDLE)
```

State indicator dot colors:
- **IDLE**: dim blue (60, 120, 180)
- **LISTENING**: bright blue (80, 180, 255) — pulse oscillation
- **PROCESSING**: amber (255, 200, 80) — hue shifts ±60°
- **SPEAKING**: teal (100, 220, 180) — steady
